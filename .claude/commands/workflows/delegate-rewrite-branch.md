Use skill `delegate-prose`.

Target: the prose changed by the current branch against `main`.

Have the peer rewrite the target, starting from the purpose and source material of the text, and edit the files where a change is warranted.

Keep what the text must say and the behavior of any code around it. If the peer cannot run or finish, ask me whether you should do the rewrite yourself.
