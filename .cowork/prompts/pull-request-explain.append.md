When a pull request changes what an agent sees or how it is instructed, make that change visible whenever it would help reviewers assess or refine the behavior. This includes prompts, system or persona instructions, workflow guidance, skills, tool descriptions or schemas, and similar model-facing text or interfaces. Prefer a compact representative excerpt or before-and-after comparison over describing the change only in prose, because the exact wording and shape are often what need review and iteration. Show only the smallest useful artifact; do not dump large generated prompts or repeat material that adds no explanatory value.
