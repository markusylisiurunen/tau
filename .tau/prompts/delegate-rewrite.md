---
label: "delegate rewrite of text"
---

Use skill `delegate-prose`.

Have the peer rewrite the text or file I specify, starting from the purpose and source material of the text. Ask me for the target if I have not given one. The peer edits a file in place and returns any other text to me.

Keep what the text must say and the behavior of any code around it. If the peer cannot run or finish, ask me whether you should do the rewrite yourself.
